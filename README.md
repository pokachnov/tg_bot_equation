# 🧮 Telegram-бот для решения уравнений

Удобный Telegram-бот на Python, который помогает быстро решать **квадратные** и **кубические** уравнения. Бот не просто выдает ответ, но и визуализирует решение квадратных уравнений с помощью графиков.

---

## ✨ Основные возможности

* **Решение квадратных уравнений:** Полный расчет корней через дискриминант или теорему Виета.
* **Решение кубических уравнений:** Нахождение действительных корней.
* **Автоматические графики:** Для каждого квадратного уравнения бот строит параболу и отправляет её пользователю.

---

## 📊 Динамические графики (sine_plot.png)

В проекте используется файл `sine_plot.png`. 

⚠️ **Обратите внимание:** Этот файл **автоматически перезаписывается** каждый раз, когда кто-то решает квадратное уравнение в боте. Бот генерирует актуальный график функции (параболу) с помощью библиотек `matplotlib` и `numpy`, сохраняет его под именем `sine_plot.png` и отправляет пользователю. 

---

## 🛠️ Технологии

* **Python 3.11+**
* **pyTelegramBotAPI** (telebot) — для работы с Telegram API.
* **matplotlib** & **numpy** — для генерации и отрисовки графиков уравнений.
* **python-dotenv** — для безопасного хранения токенов.

---

## 🚀 Настройка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/pokachnov/tg_bot_equation.git
cd TG_BOT
```
### 2. Установка зависимостей
```bash
pip install pyTelegramBotAPI matplotlib numpy python-dotenv
```

### 3. Настройка переменных окружения
Создайте в папке `TG_BOT` файл **`token.env`** и добавьте туда ваш токен от BotFather:

```env
BOT_TOKEN=ваш_токен_от_botfather
```
*Никогда не публикуйте этот файл на GitHub!*

### 4. Запуск бота
```bash
python main.py
```
